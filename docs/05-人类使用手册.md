# 人类使用手册

这份文档里**没有一条命令需要你敲**。命令是 AI 的事。

你要做的只有三件：**说清楚要什么**、**在被问到时拍板**、**验收**。

---

## 第一次：两步开工

**0. 先确认命令行版的 AI 能用**（只需一次）。桌面 App 登录了**不等于**命令行登录了，这是两套凭据：

```
claude auth login
```

> **命令行用不了怎么办？** 很多人的 `claude` 被第三方服务商（GLM、Kimi 之类）改过配置，OAuth 登录会失败。
> 不用折腾——跳过这步，第 1 步改用 `--desktop`，在桌面 App 里开会话，效果一样。

**1. 一条命令拉起整支团队。** 在项目目录执行：

```
node scripts/launch.mjs
```

| 情况 | 用这个 |
|---|---|
| 命令行凭据正常 | `node scripts/launch.mjs`（自动开好几个终端标签） |
| 命令行用不了 / 就想用桌面 App | `node scripts/launch.mjs --desktop`（建好 worktree 和简报，告诉你每个会话开在哪、贴什么） |
| 先看它打算干什么 | `node scripts/launch.mjs --print` |

启动前会做一次凭据自检。两条路都不通时它会直接停下来并给出修法，不会开出一堆报错窗口。

它会自动给每个 Worker 开好独立 worktree、生成各自的任务简报，然后在 Windows Terminal 里开出几个标签页，每个标签页一个 AI 会话：

| 标签 | 身份 | 干什么 |
|---|---|---|
| `coord-01` | 协调器 | **你只跟它说话**：接需求、汇报进度、拿不准的来问你 |
| `contract-01` | 契约 Worker | 自己领契约类任务（接口定义、共享类型、数据库迁移） |
| `dev-01` | 开发 Worker | 自己领业务任务 |
| `rev-01` | 审查者 | 自己审送上来的任务，通过就合并 |

后面三个**不用管，也不要在里面下指令**，它们自己拉活干。

> 头几条命令会弹权限确认，点「总是允许」。想彻底免打扰见文末。

**2. 在 `coord-01` 那个标签里说出你要做什么。** 像跟一个刚入职的技术负责人说话那样：

> 我要做一个企业内部的报销系统。员工提交报销单，主管审批，财务打款。
> 先做 Web 端，移动端以后再说。要能导出 Excel 给财务对账。
> 三周内出个能演示的版本。

它会反问你几个边界问题（比如"报销单被驳回后能改吗"、"金额上限谁定"），问完给你一份任务清单让你确认。确认完，你说"开始吧"——然后 Worker 标签页就开始自己动了。

> 想先练手，不碰真项目？在协调器标签里说"**帮我建个练习沙箱**"，它会生成一个待办清单 demo，你可以把整套流程走一遍，删掉重来随便折腾。

## 日常：你只会说这几句话

| 你说 | 会发生什么 |
|---|---|
| **"开始吧" / "继续"** | 它跑一轮：回收掉线任务 → 挑出能做的 → 开分支实现 → 跑测试 → 自审 → 合并。做完汇报三句话 |
| **"现在什么情况"** | 它去读真实状态（不是凭印象），告诉你做完了什么、在做什么、卡在哪 |
| **"这个用方案 B"** | 记下你的裁决，解除阻塞，继续推进 |
| **"登录页报错了"** | 建一个修复任务，走正常流程（不会热修绕过检查） |
| **"这个功能不做了"** | 停掉并记原因，问你要不要从清单里删掉 |
| **"再加一个功能：……"** | 追加任务，检查会不会和在做的东西撞车，撞了就排队 |
| **"先停"** | 存档当前进度，告诉你下次从哪继续 |
| **"换个 AI 接手"** | 新会话贴一次开场白，它自己从仓库把事实读回来——你不用复述任何历史 |

就这些。**不用记命令，不用看 JSON，不用管分支。**

---

## 它会来找你的三类事（也只有这三类）

它被要求：技术细节自己定，**这三类必须停下来问你**。

**1. 产品取舍**
> 报销单驳回后，是让员工改原单重交，还是必须新建一单？
> 改原单：员工方便，但审计追溯会断。新建一单：审计清楚，但员工会嫌烦。
> 我建议新建一单，因为财务系统通常要求单号不可复用。你定。

**2. 风险操作**
支付、权限、隐私合规、生产发布、删数据、不可逆的数据库变更——一律先问。

**3. 你自己说矛盾了**
> 你上周说"所有人都能看全部报销单"，今天说"员工只能看自己的"。以哪个为准？

回答就是一句人话："按第二个来" / "新建一单" / "先别发生产"。它会把你的原话记进决策档案，以后不再重复问。

**它不会问你**：用什么库、变量怎么命名、目录怎么放、测试怎么写。问了你可以直接说"这种你自己定"。

---

## 你会看到的汇报长这样

每轮结束它只说三句：

> **做完了**：报销单提交接口写完并合并了，覆盖了金额为负、超限额、重复提交三种失败情况，测试全绿。
> **下一步**：做主管审批流程，预计这一轮能出来。
> **要你定的**：没有。

或者：

> **做完了**：审批接口写完了，但没合并。
> **下一步**：等你决定后继续。
> **要你定的**：主管休假时的代理审批要不要做？不做的话休假期间单子会全堆着。

---

## 三件你该知道的事

**1. 它没法糊弄你。**
"我做完了"这句话在这套架构里不算数。任务想标记完成，必须有真实的 Git 提交、工具亲自跑出来的测试退出码、每条验收条件对应的具体证据。手写"测试通过"会被系统直接拒绝。所以它跟你说"做完了"的时候，是真的做完了。

**2. 它断了也不会丢。**
某个标签页崩了、上下文塞满了、你手滑关掉了——进度、决策、每一步的交接记录全在硬盘上。关掉的标签重新 `node scripts/launch.mjs --only dev-01` 拉起来，它自己把事实读回来接着干，**你不需要复述任何历史**。半截的活会被协调器标成"中断"，分支和提交都保留，不会重写。

**3. 审查是真独立的。**
实现和审查是两个不同的会话、不同的 agent id，审查者看不到实现者的思路，只能看提交、diff 和证据。系统也禁止自审。所以"通过"不是自己给自己盖章。

**4. 它不会自己宣布完成。**
只要还有任务没走完整流程，它就不许说"项目完成了"。你听到"完成"，可以去看任务清单核对。

## 什么时候该警惕

| 现象 | 说明 | 你该说 |
|---|---|---|
| 连着几轮都在"修上一轮的问题" | 任务可能拆错了，或需求本身没想清 | "停一下，把这块重新拆一遍" |
| 它问你技术细节 | 它偷懒了 | "这种你自己定，别问我" |
| 它说"基本完成"、"应该没问题" | 它在含糊 | "跑验证给我看结果" |
| 它建议你放宽某个检查 | 这是在拆自己的安全网 | "不改配置，按规则补齐" |
| 进度好几轮不动 | 多半卡在等你拍板 | "现在什么情况，卡在哪" |

## 开一个新项目

一条命令建好仓库和控制目录（在 `ai-project-orchestrator` 目录里执行）：

```
node scripts/init-project.mjs --path ../我的游戏 --name "我的游戏"
```

它**刻意不猜技术栈**——需求、技术栈、路径归属、验证命令全部留白，由协调器问清你之后自己填。然后：

```
cd ../我的游戏
node scripts/launch.mjs
```

在 `coord-01` 里直接说你要做什么。它会按这个顺序走，每步跟你确认：

1. 问清需求（用户是谁、核心流程、明确不做、上线标准），写进 `docs/product.md`
2. 给 2--3 个技术栈方案讲清代价，你拍板，写进 `docs/architecture.md`
3. 按真实目录结构重写路径归属，把构建配置和 CI 锁给契约角色
4. 设好验证命令（此时还跑不通，这是对的——先定目标）
5. 拆任务给你确认
6. 开始干活，第一个任务就是把项目骨架和验证命令做出来

**每个项目是独立的一套**：自己的仓库、自己的控制目录、自己的一批标签。切项目就在旧项目的协调器里说「先停」，关掉标签，去新项目再 `launch`。

## 团队怎么调

改 `<项目>-control\team.json`，然后重新跑一次 `node scripts/launch.mjs`：

| 想要 | 怎么改 |
|---|---|
| 多几个人干活 | `members` 里加 worker，**同时**把 `agents.json` 的 `maxConcurrentWorkers` 调到一样大（席位多于上限会空转，启动器会警告你） |
| 换成别的 AI | 改 `agentCommand`，例如 `["codex", "{{KICKOFF}}"]` |
| 不同角色用不同模型 | 给那个成员加 `"model": "opus"`（或 `sonnet`、完整模型 ID）；没写的成员用 `agentCommand` 里的默认 |
| 某个人专门管某类活 | 改那个 worker 的 `taskRoles` |
| 只重启某一个 | `node scripts/launch.mjs --only dev-01` |
| 不想弹权限窗 | `agentCommand` 里把 `acceptEdits` 换成 `bypassPermissions`——它会跳过**所有**权限检查，只在你信得过这个项目时用 |
| 不是 Windows | `node scripts/launch.mjs --print`，它会打印每个窗口该执行的命令，你自己开终端粘贴 |

**收工**：在协调器标签里说「先停」。它会存档、释放租约，然后你关掉所有标签。
下次接着干：再跑一次 `node scripts/launch.mjs`，说「继续」。

---

## 你自己要做的两件事

**1. 定期推代码。** AI 会做本地提交和合并，但推到公司仓库、什么时候发布，是你的决定，它不会替你做。

**2. 别在 Worker 标签里下指令。** 那几个窗口是自动的，你插话会打乱它们的循环。有事都跟协调器说。
