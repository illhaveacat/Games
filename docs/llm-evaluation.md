# 对话理解接入大模型（LLM）：费用与隐私方案

> 状态：**已人类拍板**（2026-09-28）。本文评估不涉及代码改动；代码接入留给后续开发任务。
> 背景：`docs/product.md` 要求 NPC "能听懂玩家说的话并给出针对性反馈，不是简单关键词匹配"。目前开场关卡用的是规则/关键词匹配，DIALOG-001 会补齐常见说法，但规则的理解上限低，自由表达还是会被漏判。

## 一句话结论

建议采用 **"规则优先、听不懂再问大模型"的混合方案**：绝大多数常见说法仍由免费的规则当场处理，只有规则拿不准的句子才发给大模型。这样费用和数据外发量都能压到最低。**任务推进和发奖仍由我们自己的服务器校验**，大模型只负责"理解这句话是什么意思"和"用角色口吻回一句"，不能直接给玩家加分。

## 方案怎么工作

1. 玩家说一句话 → 服务器先用规则判断（和现在一样，免费、即时）。
2. 规则明确命中 → 直接推进，不调用大模型。
3. 规则判断不了 → 把**这一句话 + 当前任务步骤的说明**发给大模型，让它从本步骤允许的几种意图里选一个（如"要加糖 / 不要加糖 / 堂食 / 打包 / 没听懂"），并以咖啡师口吻回一句。
4. 服务器检查大模型选的意图是否属于当前步骤、是否合法，再决定是否推进任务、是否发奖。
5. 大模型超时、出错或超出当天预算 → 自动退回纯规则模式，游戏照常可玩，只是理解能力回到现在的水平。

## 费用估算

价格为 Anthropic 官方 API 当前标价（每百万 token）。估算假设每次调用约 900 个输入 token（角色设定 + 当前步骤说明 + 玩家这句话）、约 80 个输出 token（意图 + 一句回复）。

| 模型 | 输入 / 输出单价 | 每次调用约 | 一名玩家打完第一关（约 10 次调用，含重说） | 每月 1000 名玩家、每人约 30 次调用 |
|---|---|---|---|---|
| Claude Haiku 4.5（`claude-haiku-4-5`） | $1 / $5 | 约 $0.0013 | 约 $0.013 | 约 $40 |
| Claude Sonnet 5（`claude-sonnet-5`） | $2 / $10 | 约 $0.0026 | 约 $0.026 | 约 $80 |
| Claude Opus 5（`claude-opus-5`） | $5 / $25 | 约 $0.0065 起（默认会先"思考"，实际输出更多，可能到 $0.01） | 约 $0.07–0.10 | 约 $200–300 |

说明：

- 上表按"每句话都调用大模型"算，是**上限**。采用混合方案后，规则能处理的常见说法不花钱，实际费用会明显更低，具体比例要上线后看真实数据。
- 玩家越多、关卡越多，费用线性增长。**必须设每日费用上限**：达到上限自动退回纯规则模式，不会产生意外账单。
- 另有一次性的开发成本：约 1 个开发任务（接入 + 兜底 + 测试）和 1 个审查。
- 选哪个模型建议先做一个小测试：拿 50–100 句真实的玩家说法（包括口语、语法错误、弯引号之类），分别让几个模型判断，比较准确率和响应速度，再按"够用且最便宜"来选。理解一句点单用语通常不需要最强的模型，但以测试结果为准。

## 隐私与合规

接入后，**玩家输入的英文句子会发送到 Anthropic 的服务器**做处理。需要注意：

- **只发必要内容**：只发这一句话和当前任务步骤的说明，不发玩家身份、设备信息、存档或历史记录。游戏本身没有账号系统，本来也没有这些信息。
- **需要在隐私说明里告知玩家**：写明"你输入或说出的英文内容可能会发送给第三方 AI 服务商用于理解对话"。游戏面向公众发布，这一条不能省。
- **数据保留**：第三方服务商对 API 请求数据的保留期限和用途，以 Anthropic 当时的商业条款和数据政策为准，**上线前需要人类确认一遍条款**。如有更严格的要求（比如零保留），可以向服务商单独申请，但不是默认就有。
- **语音**：语音识别目前用的是浏览器自带功能（Chrome 的语音识别通常也会把录音交给浏览器厂商的服务器处理，这一点同样应写进隐私说明），与本方案无关；本方案只发识别出来的文字，不发录音。
- **未成年人**：如果目标玩家可能包含未成年人，各地法规对收集和处理未成年人数据有额外要求，需要人类在上线前确认。
- **密钥安全**：API 密钥只放在服务器上，绝不下发到浏览器。

## 其他选项（供对比）

| 选项 | 费用 | 理解能力 | 隐私 | 主要问题 |
|---|---|---|---|---|
| A. 只用规则（现状 + DIALOG-001） | 免费 | 低，达不到 product.md 的要求 | 数据不外发 | 自由表达会被漏判 |
| B. 混合方案 + 云端大模型（**推荐**） | 按用量付费，可设上限 | 高 | 玩家文字发给第三方，需要告知 | 需要 API 账号和费用预算 |
| C. 浏览器里跑小型开源模型 | 免费 | 中 | 数据不外发 | 首次要下载几百 MB 模型，低端电脑和手机很慢甚至跑不动，开发量大 |

## 需要人类决定的事

1. **是否接受把玩家的英文输入发给第三方 AI 服务商**（需在隐私说明里告知玩家）。
2. **每月费用上限**，例如先设 $20/月试运行，超出自动退回纯规则模式。
3. **API 账号**：需要一个 Anthropic API 账号和密钥（由人类注册、付费并提供，协调器和开发不代为注册）。
4. **模型选择**：同意先做小测试再选，还是直接指定一个模型。
